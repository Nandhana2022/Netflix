# 🎬 Netflix Clone (React + Vite)

A Netflix-inspired web app built with **React (Vite)**.  
Includes a modern UI, movie browsing, and responsive design.

---

## 🚀 Live Preview
👉 [Netflix Clone App](https://netflix-zeta-seven.vercel.app/)

---

## 📦 Features
- Netflix-like homepage UI
- Responsive design with TailwindCSS
- Browse and explore movie sections
- Reusable React components
- Clean layout and animations

---

## 🛠 Tech Stack
- React + Vite
- TailwindCSS
- React Router (for navigation)
